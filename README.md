# SignalBot

Android AI chart scanner. It captures the visible screen, sends a compressed chart screenshot to the OpenAI Responses API, and displays a floating BUY / SELL / WAIT panel.

## Build

GitHub Actions -> **Build Android APK** -> **Run workflow**.

## On the phone

1. Open SignalBot.
2. Enter your OpenAI API key.
3. Tap **START AI SCANNER**.
4. Allow **Display over other apps**.
5. Allow the Android **screen capture** prompt.
6. Open MT5/Quotex or another charting app.
7. Keep the chart clearly visible; the scanner refreshes about every 5 seconds.

The signal is decision support only and is not a profit guarantee.
